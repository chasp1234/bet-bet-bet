# IRL Bet Casino — PRD

## Vision
A crypto betting platform with two clearly separated product pillars:
1. **IRL Bets** — real-life event betting via live stream rooms or proof-based rooms
2. **Games** — casino-style mini-games in a separate lobby and UX lane

The product must feel premium, animated, modern, and clearly segmented so users never confuse real-life event betting with instant games.

## Product Sections
- Home
- IRL Bets
  - Live Rooms
  - Proof Rooms
- Games
- Wallet
- Profile / History

## UX Principles
- Strong separation between IRL Bets and Games
- Premium dark UI with motion and high clarity
- Pool transparency and estimated payout visibility
- Clear room/private/public states
- Wallet and payments treated seriously

## MVP Build Plan
1. Home redesign from scratch
2. IRL Bets section architecture
3. Games lobby section architecture
4. Wallet preview section
5. Global navigation and section switching
6. Netlify-ready deployment setup
